# Examples: Mathegenic Writing Coach in Action / 使用示例

## Example 1: Parent Scenario / 家长场景 — "My child can't start writing / 我的孩子写不出来"

**User input / 用户输入**: "My 11-year-old son has to write a story for school and he's been staring at a blank page for an hour. He asked me if he can use ChatGPT to write it. What should I do?"

"我 11 岁的儿子学校要写一篇故事，他已经盯着空白纸发呆一小时了。他问我能不能用 ChatGPT 帮他写。我该怎么办？"

**Diagnosis / 诊断**:
- Role / 角色: Parent / 家长
- Stage / 阶段: Structured Awakening / 结构化觉醒期 (~9-13, restructuring dip / 重构低谷)
- Goal / 目标: Help child start a narrative story without AI ghostwriting / 帮助孩子在不让 AI 代写的情况下开始写故事

**Skill response / Skill 响应**:

First, validate the child's struggle: "Tell your son that professional writers also stare at blank pages. It means his brain is working."

首先，认可孩子的挣扎："告诉你儿子，专业作家也会盯着空白页发呆。这说明他的大脑正在工作。"

Then, provide a three-step scaffold:

然后，提供三步脚手架：

**Step 1: Draw before writing (10 min) / 第一步：先画再写（10 分钟）**
Have your son draw a simple map of the story world. It doesn't need to be artistic — just "Where does the story start? Where does it go? Where does it end?" This converts the abstract task "write a story" into the concrete task "design a space."

让你儿子画一张简单的故事地图。不需要画得多好看——只需要"故事从哪里开始？经过哪里？到哪里结束？"这样就把抽象的"写作文"任务变成了具体的"设计空间"任务。

**Step 2: Use AI as a question-asker, not a writer (5 min) / 第二步：把 AI 当作提问者，不是写手（5 分钟）**
Copy this prompt into ChatGPT together with your son:

把这段提示词复制到 ChatGPT，和你儿子一起用：

```
My son is writing a story. He has drawn a map of [describe the map].
Please do NOT write the story for him.
Instead, ask him ONE question at a time to help him think:
1. Who is the main character and what do they want?
2. What is one place on the map where something surprising could happen?
3. If the main character reaches the end, how are they different from when they started?

Ask the first question now. Wait for his answer before asking the next.
```

**Step 3: Write one section at a time (15 min) / 第三步：一次只写一段（15 分钟）**
Tell your son: "You only need to write the beginning today. One paragraph." Lower the threshold. Tomorrow, write the middle. The day after, the end.

告诉你儿子："今天你只需要写开头。一段就够了。"降低门槛。明天写中间，后天写结尾。

**Parent talk script for this situation / 该场景家长话术**:
- "Let's not worry about the whole story. What's one tiny scene you can picture?" / "我们先不担心整篇故事。你能想到的最小的一个画面是什么？"
- "If your main character were standing right here, what would they be looking at?" / "如果你的主角就站在这里，他/她会看到什么？"
- "You don't need to write well yet. You just need to write what you see." / "你现在不需要写得多好。你只需要把你看到的写出来。"

## Example 2: Teacher Scenario / 教师场景 — "Design a lesson based on a textbook text / 基于课文设计一节课"

**User input / 用户输入**: "I'm a middle school Chinese teacher. I want to use your framework to teach 'A Drop of Water Passes Through Lijiang.' Can you give me a complete lesson plan with AI prompts and worksheets?"

"我是初中语文老师。我想用你的框架来教《一滴水经过丽江》。能给我一份包含 AI 提示词和学习单的完整教案吗？"

**Diagnosis / 诊断**:
- Role / 角色: Teacher / 教师
- Stage / 阶段: Structured Awakening / 结构化觉醒期 (~9-13, textbook-based writing / 基于课文的写作)
- Goal / 目标: Convert textbook reading into AI-scaffolded travelogue writing / 将课文阅读转化为 AI 支架游记写作

**Skill response / Skill 响应**:

Provide the complete **Workflow Plan** + matching **Prompt Cards** + **Worksheets**:

提供完整的**操作流程** + 匹配的**提示词卡** + **学习单**：

### Workflow: "Borrowing a Special Pair of Eyes" (3-4 class periods) / 操作流程："借一双特别的眼睛"（3-4 课时）

**Phase 1: Discover the Text's Mechanism (1 period) / 第一阶段：发现文本机制（1 课时）**
- Student reads the text. / 学生阅读课文。
- In pairs, students use Prompt 1.11 (Text Writing Discovery) with AI to uncover: How does the water perspective work? What is the route? What details make it vivid? / 两人一组，使用提示词 1.11（文本写法发现）与 AI 一起探究：水的视角如何运作？路线是什么？哪些细节让描写生动？
- Output: Each pair fills out a "Writing Mechanism Map" worksheet. / 输出：每组填写一张"写法机制图"学习单。

**Phase 2: Design Your Own Perspective and Route (1 period) / 第二阶段：设计自己的视角和路线（1 课时）**
- Student chooses a location (school, hometown park, old street) and uses Prompt 1.12 (Perspective Generator) to get 8 perspective options. / 学生选择一个地点（校园、家乡公园、老街），使用提示词 1.12（视角生成器）获取 8 个视角选项。
- Student selects one perspective and uses Worksheet 2.1 (Route Design Card) to plan the route. / 学生选择一个视角，使用学习单 2.1（路线设计卡）规划路线。
- AI check: Use Prompt 1.13 (Route Design) to validate that the route has emotional progression, not just location changes. / AI 检查：使用提示词 1.13（游踪路线设计）验证路线是否有情感递进，而非仅地点变化。

**Phase 3: Language Pattern Lab (0.5 period) / 第三阶段：语言模式实验室（0.5 课时）**
- Teacher introduces 3 sentence patterns from the text. / 教师介绍课文中的 3 个句式模式。
- Students write 2 sentences per pattern. / 学生每个模式写 2 个句子。
- Use Prompt 1.15 (Language Pattern Lab) to generate additional examples for comparison. / 使用提示词 1.15（语言模式实验室）生成更多示例供比较。
- Output: Worksheet 2.4 (Language Pattern Experiment Sheet). / 输出：学习单 2.4（语言模式实验单）。

**Phase 4: Text Roaming and Material Gathering (0.5-1 period) / 第四阶段：文字漫游与素材收集（0.5-1 课时）**
- Student uses Prompt 1.16 (Text Roaming Engine) to "walk through" their designed route. / 学生使用提示词 1.16（文字漫游引擎）"漫步"于自己设计的路线。
- AI asks observational questions at each stop. / AI 在每个站点提出观察性问题。
- Student records answers as raw material. / 学生记录回答作为原始素材。
- Output: "Roaming Log" document. / 输出："漫游日志"文档。

**Phase 5: Structure and First Draft (1 period) / 第五阶段：结构与初稿（1 课时）**
- Student uses Worksheet 2.3 (Story Structure Table) to organize the roaming log into a narrative structure. / 学生使用学习单 2.3（故事结构表）将漫游日志组织成叙事结构。
- AI check: Use Prompt 1.17 (Structure Mirror) to identify gaps. / AI 检查：使用提示词 1.17（结构镜子）识别漏洞。
- Student writes first draft independently. / 学生独立写作初稿。

**Phase 6: Feedback and Revision (homework) / 第六阶段：反馈与修改（作业）**
- Student uses Prompt 1.8 (Reflective Reader Feedback) to get AI reader comments. / 学生使用提示词 1.8（反思式读者反馈）获取 AI 读者评论。
- Student fills out Worksheet 2.5 (Revision Explanation Sheet). / 学生填写学习单 2.5（修改说明表）。
- Student submits final draft + all process materials. / 学生提交终稿 + 所有过程材料。

**Evaluation / 评估**: Use Evaluation Tool 3.2 (Project Assessment Dimensions) — 20% structure, 15% language exploration, 20% plot logic, 15% character awareness, 15% AI usage quality, 15% revision reflection.

使用评估工具 3.2（项目作品评估维度）—— 结构 20%、语言探索 15%、情节逻辑 20%、角色意识 15%、AI 使用方式 15%、修改反思 15%。

## Example 3: Advanced User Scenario / 高级用户场景 — "Convert any text into an AI scaffold / 将任意课文转化为 AI 支架"

**User input / 用户输入**: "I really like your 'A Drop of Water' case. Can you show me how to apply the same logic to 'From Baicao Garden to Sanwei Study Room' (from the textbook)? I want the full scaffold."

"我很喜欢你的《一滴水》案例。能展示如何把同样的逻辑应用到《从百草园到三味书屋》吗？我想要完整的支架。"

**Diagnosis / 诊断**:
- Role / 角色: Teacher / 教师
- Stage / 阶段: Structured Awakening / 结构化觉醒期 (textbook conversion / 课文转化)
- Goal / 目标: Apply the 8-scaffold model to a different textbook text / 将八支架模型应用到另一篇课文

**Skill response / Skill 响应**:

First, analyze the source text:

首先，分析原文：

- **Text / 课文**: "From Baicao Garden to Sanwei Study Room" (Lu Xun) / 《从百草园到三味书屋》（鲁迅）
- **Core writing mechanism / 核心写作机制**: Spatial transition + contrast between two worlds (freedom vs. discipline) + childhood memory through adult eyes / 空间转换 + 两个世界的对比（自由 vs 规矩）+ 成人视角回望童年记忆
- **Key structural feature / 关键结构特征**: The text is organized by space (Baicao → Sanwei), but the emotional core is the contrast between the two spaces. / 文本以空间组织（百草园 → 三味书屋），但情感核心是两个空间之间的对比。

Then, adapt the 8 scaffolds:

然后，适配八支架：

**Scaffold 1 — Text Writing Discovery / 文本写法发现**:
Change the focus from "water perspective + route" to "spatial contrast + memory tone."
将焦点从"水视角 + 路线"转向"空间对比 + 记忆 tone"。
Key questions / 关键问题: How does Lu Xun make Baicao Garden feel like a paradise? What specific details create the feeling of "freedom"? How does the tone shift when entering Sanwei Study? 鲁迅如何让百草园感觉像天堂？哪些具体细节创造了"自由"的感觉？进入三味书屋时 tone 如何转变？

**Scaffold 2 — Perspective Generator / 视角生成器**:
Instead of "non-human narrator," the perspectives could be:
不局限于"非人称叙述者"，视角可以是：
- A childhood object (toy, insect, plant) that witnessed both spaces / 一个见证过两个空间的童年物件（玩具、昆虫、植物）
- An adult memory returning to the place / 一个回到此地的成人记忆
- A sound (laughter, reading voice) that echoes in both spaces / 一种在两个空间中回响的声音（笑声、读书声）

**Scaffold 3 — Route Design / 游踪路线设计**:
Instead of a "travel route," design a "contrast route": Space A (free) → Transition → Space B (structured). Each stop must highlight a contrast dimension (sights, sounds, activities, feelings).
不设计"旅行路线"，而是设计"对比路线"：空间 A（自由）→ 过渡 → 空间 B（规矩）。每个站点必须突出一个对比维度（视觉、声音、活动、感受）。

**Scaffold 4 — Detail Amplification / 景物细节放大**:
Focus on the five senses, but with an emphasis on how the SAME sense changes between the two spaces. For example: "What sounds did you hear in Baicao? What sounds in Sanwei? How does the change in sound reflect the change in feeling?"
聚焦五感，但强调同一个感官在两个空间之间的变化。例如："百草园里你听到了什么声音？三味书屋里呢？声音的变化如何反映感受的变化？"

**Scaffold 5 — Language Pattern Lab / 语言模式实验室**:
Patterns based on Lu Xun's style / 基于鲁迅风格的句式：
- Pattern / 模式: "In [Place A], I could [free action], but in [Place B], I could only [restricted action]." / "在[地点A]，我可以[自由动作]，但在[地点B]，我只能[受限制的动作]。"
- Pattern / 模式: "I thought [Place B] would be [negative expectation], but actually it was [surprising nuance]." / "我原以为[地点B]会是[负面预期]，但实际上它[出人意料的微妙之处]。"

**Scaffold 6 — Text Roaming / 文字漫游**:
AI guides the student through their own two spaces, asking: "What is the Baicao-equivalent in your life? What is the Sanwei-equivalent? What happened in the transition?"
AI 引导学生漫步于他们自己的两个空间，问："你生活中的'百草园' equivalent 是什么？'三味书屋' equivalent 是什么？在过渡中发生了什么？"

**Scaffold 7 — Structure Mirror / 结构镜子**:
Check / 检查: Does the contrast between the two spaces become sharper as the text progresses? Is there a moment where the narrator realizes something about the second space that wasn't obvious at first? 两个空间之间的对比是否随着文本推进而更加鲜明？有没有一个时刻，叙述者对第二个空间的理解发生了起初并不明显的新认识？

**Scaffold 8 — Revision Explainer / 修改说明支架**:
Same as original. / 与原版相同。

**Final output / 最终输出**: A complete 8-scaffold package customized for the new text, with all prompts rewritten to match the text's specific writing mechanism.

一份为新课文定制的完整八支架方案，所有提示词都根据该文本的特定写作机制重写。
